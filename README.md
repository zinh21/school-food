# 🍚 오늘의 급식

학교별 오늘의 급식을 확인할 수 있는 Streamlit 웹앱입니다.

NEIS 교육정보 개방포털의 급식식단정보 API를 이용합니다.

## ✨ 주요 기능

- 📅 날짜별 급식 조회
- 🏫 여러 학교 선택
- 🍚 아침 / 점심 / 저녁 급식 확인
- 📆 일주일 급식 확인
- 🔥 칼로리 그래프
- 📊 학교별 급식 비교
- 📱 모바일에서도 사용 가능

## 🏫 기본 학교

당곡고등학교

## 🛠️ 사용 기술

- Python
- Streamlit
- Pandas
- Plotly
- NEIS Open API

## 🚀 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
